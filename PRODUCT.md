# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
React app with local Windows Node.js backend, as requested.
## Users
The owner of an Eufy video doorbell, testing live viewing and HomeBase connectivity locally.
## Product Purpose
Sign in locally, discover real devices and display a selected doorbell stream. Show actual connection and playback errors.
## Capabilities and Constraints
Camera monitor interface selected by the user. Use an existing protocol client for interoperability. Decompiled Android libraries do not run on Windows. Hardware model is not yet known. APK findings are evidence, not proven protocol implementations. No simulated devices may appear as real devices.
## Evidence on Hand
analysis/streaming/FINDINGS.md and extracted APK capability/command metadata.
